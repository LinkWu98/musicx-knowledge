**和弦入门把零散的音组织成可识别、可连接的组合，让一段旋律有简单的伴奏。**

## 调性与音程

**调性建立音乐的中心，音程说明两个音的距离。**

C 大调以 C 为主音，基本音阶为 C、D、E、F、G、A、B；A 自然小调使用同一组音，但围绕 A 形成中心。用哪些音与把哪个音听作中心，是不同的问题；不能只凭开头第一个音判断调性。

三度、五度按音名位置计数，再用大、小、纯等性质区分具体距离。关于音程命名、频率比例与律制，可查阅[从频率比到音阶](musicx-knowledge://article/theory.scales-tuning-and-chords)。这里把注意力放在这些关系怎样落到键盘上。

## 三和弦的组成

**大三和弦与小三和弦都包含根音、三音、五音，区别主要在三音的位置。**

从根音向上看，大三和弦的大三度为四个半音，小三和弦的小三度为三个半音；两者的五音都与根音构成七个半音的纯五度。这是十二平均律键盘上的计数方式。

先认识四个常见组合：

- C 大三和弦：C—E—G，符号写 C。
- F 大三和弦：F—A—C，符号写 F。
- G 大三和弦：G—B—D，符号写 G。
- A 小三和弦：A—C—E，符号写 Am，m 表示小三和弦。

可以先逐个弹组成音，再同时弹响，边听边对应和弦符号。这里的 C 有时指单音、有时指和弦，要根据谱面上下文区分。三和弦的构成与符号可参见 [Open Music Theory：三和弦与七和弦](https://openmusictheory.github.io/triads.html)。

## 转位与平稳连接

**转位改变哪个和弦音放在最低处，组成音仍属于同一个和弦。**

C 和弦可以从低到高排列成 C—E—G、E—G—C 或 G—C—E，分别是原位、第一转位和第二转位。弹奏时不必每次都从根音向上堆叠，可以寻找离当前手位较近的排列。

例如右手把 C 和弦弹成 C—E—G，再接 Am 的 C—E—A，只需把 G 移到 A，另外两个音保持。这个例子让耳朵听见共同音，也减少了手的跳动。

如果左手另外弹了根音，整个和弦的最低音仍由左手决定。右手用了“转位手形”，不一定表示双手整体形成了转位和弦。

## 根音与和弦伴奏

**左手给出低音，右手表达和弦，先让换和弦与节拍对齐。**

用 C → Am → F → G 做一个简单循环。每小节一个和弦，左手弹相应根音 C、A、F、G，右手弹和弦音。开始可以都在第一拍进入并保持，不急着加入复杂节奏。

熟悉后，右手尝试更近的排列，再把同时发声的和弦音拆开依次弹奏，形成简单分解和弦。变化时尽量维持相同速度，才能比较不同伴奏织体的听感。

## 与旋律结合

**伴奏的作用是支持旋律，音越多并不一定越合适。**

先选择已有和弦标记的短旋律，确认在哪一拍换和弦，再让左手只弹根音。能听清旋律以后，再逐步加入和弦音、分解方式和轻重变化。

需要更丰富的和弦色彩，可以读[爵士和声](musicx-knowledge://article/learning-path.jazz-harmony)；需要把伴奏弹得有节奏变化，可以读[节奏律动](musicx-knowledge://article/learning-path.rhythm)。
