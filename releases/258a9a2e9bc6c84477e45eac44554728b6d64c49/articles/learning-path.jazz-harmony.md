**爵士和声入门先建立三件事的联系：和弦符号、组成音，以及相邻和弦怎样连接。**

## 常见七和弦

**七和弦在三和弦的基础上加入七音，先区分大七、小七与属七三种常见色彩。**

用同一个根音 C 来比较，更容易听见区别：

- Cmaj7，大七和弦：C—E—G—B，大三和弦加大七度。
- Cm7，小七和弦：C—E♭—G—B♭，小三和弦加小七度。
- C7，属七和弦：C—E—G—B♭，大三和弦加小七度。

maj7 与单独的 7 不是同一种七音。符号里的数字也不代表要同时弹七个音。“属七”在这里描述和弦类型，它在曲子中是否承担属功能，还要看上下文。七和弦结构可参见[七和弦入门](https://musictheory.pugetsound.edu/mt21c/SeventhChordsIntroduction.html)。

回到 C 大调中，可以先接触 Cmaj7、Fmaj7、Am7、Dm7、G7。它们分别由 C—E—G—B、F—A—C—E、A—C—E—G、D—F—A—C、G—B—D—F 组成。

## 级数与和弦进行

**级数描述和弦在调里的位置，便于认识不同调中相似的进行。**

在 C 大调中，D 是第二级，G 是第五级，C 是第一级。因此，常见的 ii–V–I 在这里可以弹成：

> Dm7 → G7 → Cmaj7

罗马数字的小写 ii 表示这一位置通常采用小和弦；采用七和弦时，更完整地写为 ii7–V7–Imaj7。它不是三个固定的字母：换到 F 大调，就成为 Gm7 → C7 → Fmaj7。

另一个入门循环是 Cmaj7 → Am7 → Dm7 → G7，对应 C 大调的 I–vi–ii–V。先每个和弦保持四拍，听最后的 G7 接回 Cmaj7 时的方向感，再尝试节奏变化。

## 和弦配置与声部连接

**配置决定和弦音放在哪里，声部连接决定这些音怎样走向下一个和弦。**

和弦符号通常不要求唯一的音区、排列或重复方式。以 Cmaj7 为例，可以左手弹 C，右手弹 E—G—B；整体仍表达同一个和弦。

三音与七音常能清楚表达七和弦的性质，因此可以先练“左手根音、右手三音与七音”的精简配置。关于这种导向音的思路，参见[爵士和弦配置](https://musictheory.pugetsound.edu/mt21c/JazzChordVoicings.html)。

在 Dm7 → G7 → Cmaj7 中，右手可在中音区依次弹 F—C、F—B、E—B；左手分别给出 D、G、C。这里每次只移动右手的一个音，另一个音保持，让和弦连接更平稳。它是一个入门配置例子，不是所有曲目都必须套用的手形。

## 放进实际音乐

**先保持和声清楚，再加入节奏、旋律与音区变化。**

同一个 ii–V–I，可以先用完整七和弦听色彩，再用精简配置听声部移动。随后为它配一个简单节奏，或让右手在熟悉的和弦音上弹短句。

当右手需要承担旋律时，和弦音可以减少、重新分配给左手，或放在旋律的空隙中。避免每次换和弦都用同样力度把所有音砸下去；留意旋律是否仍能听清。

七和弦熟悉后，可在[自由演奏](musicx-knowledge://article/learning-path.improvisation)中继续接触扩展音与短乐句变化。
