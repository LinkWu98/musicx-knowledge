目标：能弹喜欢的爵士、嘻哈风格钢琴曲，再逐步尝试即兴和编配。

## 主路线

**钢琴基础 → 核心入门 → 爵士和声 → 自由演奏。**

- [钢琴基础](musicx-knowledge://article/learning-path.foundations)：读谱、数拍、双手配合。
- [核心入门](musicx-knowledge://article/learning-path.chords)：大小调、三和弦、转位、简单伴奏。
- [爵士和声](musicx-knowledge://article/learning-path.jazz-harmony)：七和弦、常见进行、和弦配置。
- [自由演奏](musicx-knowledge://article/learning-path.improvisation)：扩展音、短句即兴、简单编配。

## 两条并行线

**节奏和兴趣曲目从基础期就可以开始。**

- [节奏律动](musicx-knowledge://article/learning-path.rhythm)：从稳定数拍，逐步加入切分、摇摆和伴奏节奏。
- [曲目应用](musicx-knowledge://article/learning-path.repertoire)：先弹喜欢的两到四小节，再逐步连成完整版本。

## 使用方式

每篇路线卡片只看四件事：**学什么、用什么学、用什么练、完成标准。**

- 教材与兴趣曲目一起推进，不必等《小汤》整套学完。
- 遇到具体难点，回到对应卡片选一项练习。
- 完成标准用于自我判断，不要求逐项打卡，也不表示必须全部达标才能接触后续内容。
- 《小汤》的册数只是选材参考，具体知识点以手中版本目录为准。

想了解原理时，再单独读乐理文章。例如：[音程、纯律与十二平均律](musicx-knowledge://article/theory.scales-tuning-and-chords)。
