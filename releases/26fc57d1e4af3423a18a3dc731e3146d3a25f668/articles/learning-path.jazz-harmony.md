目标：读懂常见七和弦，把一个短进行弹得清楚、连贯。

## 学什么

- maj7 大七、m7 小七、7 属七和弦。
- 先练 Cmaj7、Fmaj7、Am7、Dm7、G7。
- 和弦级数，常见的 ii–V–I 与 I–vi–ii–V。
- 和弦配置：根音、三音、七音，以及平稳的声部连接。

## 用什么学

- [七和弦入门](https://musictheory.pugetsound.edu/mt21c/SeventhChordsIntroduction.html)：查三类七和弦的区别。
- [爵士和弦配置](https://musictheory.pugetsound.edu/mt21c/JazzChordVoicings.html)：从根音加三音、七音的精简配置开始。
- 边看符号、边说组成音、边弹，听不同和弦的色彩。

## 用什么练

- Cmaj7：左手 C，右手 E—G—B。
- Dm7 → G7 → Cmaj7：C 大调的 ii–V–I。
- Cmaj7 → Am7 → Dm7 → G7：先每个和弦保持四拍。
- 再试左手弹 D、G、C，右手依次弹 F—C、F—B、E—B，体会少量移动的连接。

## 完成标准

- 能区分 maj7、m7、7，并弹出上面五个常见和弦。
- 能解释 C 大调的 ii–V–I 对应哪三个和弦。
- 能连续慢速循环一个进行，保持节拍，并减少不必要的跳动。
- 能听出几种和弦的色彩差别，用自己的词描述。
