音高、音程、音阶和和弦，都与声音的频率有关。先认识两个音之间的距离，再看这些距离怎样组成音阶与和弦，就能理解五度相生律、纯律和十二平均律各自的取舍。

## 声音与频率

**频率影响音高；在理想模型中，频率翻倍就升高一个八度。**

声音来自振动。琴弦振动带动周围空气，声波传到耳朵，便形成听觉。每秒振动多少次，称为频率，单位是赫兹，记作 Hz：440 Hz 表示每秒振动 440 次。

对于有明确音高的乐音，基频通常越高，听起来越高。钢琴的一个音还包含其他频率成分，它们共同影响音色，因此音高与音色需要分开理解。

常用调音标准把 A4 定为 440 Hz。理想情况下，它上方的 A5 是 880 Hz，下方的 A3 是 220 Hz。相邻两个 A 高低不同，却有相似的音高特征，这样的距离称为八度。

220 到 440 Hz 相差 220 Hz，440 到 880 Hz 相差 440 Hz，但两者都是翻倍。因此，八度没有固定的 Hz 差，它对应的是固定的频率比例。

## 音程与度数

**音程是两个音之间的距离；度数按音名位置数，实际大小还要看“大、小、纯”等性质。**

从 C 到 E，把 C、D、E 都算进去，一共三个音名位置，所以是三度。从 C 到 G，包含五个位置，所以是五度。音乐中还有二度、四度、六度、七度、八度等音程。

但度数并不包含全部信息。C—E 与 D—F 都是三度，前者是大三度，后者是小三度。在十二平均律键盘上，大三度包含四个半音，小三度包含三个半音；相邻琴键之间，包括黑键，是一个半音。

所以，三度不代表三倍频率，五度也不代表五倍频率。度数与频率比是描述音程的不同方式，不能把数字直接对应起来。

两个音先后响起，形成旋律音程；同时响起，形成和声音程。可以分别先后弹、同时弹 C—E 和 D—F，听听大三度与小三度的区别。读谱时的音高位置可参见[五线谱与中央 C](../notation/五线谱与中央C.md)。

## 常见音程的比例

**三度、四度、五度和八度都能对应简单的频率比；具体采用哪个比例，还取决于律制。**

律制就是安排各音频率关系的方法。先看几种常见的纯律比例，以下都按“高音频率比低音频率”表达：

- **小三度：6:5。**例如 E—G，高音频率是低音的 1.2 倍。
- **大三度：5:4。**例如 C—E，高音频率是低音的 1.25 倍。
- **纯四度：4:3。**例如 C—F，高音频率约为低音的 1.333 倍。
- **纯五度：3:2。**例如 C—G，高音频率是低音的 1.5 倍。
- **八度：2:1。**例如 C—上方 C，高音频率是低音的 2 倍。

这些是相对关系。低音取 200 Hz 时，5:4 的大三度上方是 250 Hz；低音取 400 Hz 时，上方就是 500 Hz。起点不同，音程关系相同。

这里列出的比例用于认识简单整数比，不代表钢琴上每个三度、四度、五度都精确采用这些数值。后面的十二平均律会对它们作出调整。“纯五度”中的“纯”也是音程名称的一部分，不能单凭名称判断实测频率是否恰好为 3:2。

## 泛音与协和感

**简单频率比容易让较低次的泛音重合，这是声音容易融合的一个原因；相近却不重合的成分，则可能带来摩擦感。**

### 低次泛音的重合

一个基频为 100 Hz 的声音，可以同时含有 200、300、400、500 Hz 等整数倍频率的成分。这些成分叫谐波，其中第一谐波是基频，基频以上的这些谐波也属于泛音。这里说的是理想模型，真实乐器的各个成分未必完全符合整数倍。

仅为方便计算，假设 C 是 240 Hz，按 3:2 取 G 为 360 Hz，按 9:8 取 D 为 270 Hz。240 Hz 是本文的演示基准，并非通常调音标准下的中央 C。

- **C 与 G**：C 的第 3 谐波与 G 的第 2 谐波都在 720 Hz，很低的次数就能重合。
- **C 与 D**：要到 C 的第 9 谐波与 D 的第 8 谐波，才首次在 2160 Hz 重合。

“泛音较少重合”指低次谐波中的共同成分较少，要到更高次才重合，并非时间上偶尔碰到一起。对许多乐器而言，较高次谐波往往也较弱，对听感的贡献可能较小。

### 融合与摩擦

两音中某些频率成分如果靠得很近却没有重合，还可能产生拍或粗糙感，听起来像轻微的起伏、摩擦或“挤在一起”。这有助于理解为什么在常见音色和音区中，C—D 往往比 C—G 更有摩擦感。

不过，不重合的泛音并不都会明显干扰，音色、音区和听觉经验也会影响协和感，参见[协和感研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7032667/)。音乐也会主动使用有张力的声音，因此融合程度不是判断音乐好坏的标准。

## 五度相生与音阶

**五度相生律用 3:2 连续生成音高，再用八度关系把它们放到相近的音区。**

### 以五度作为步长

八度的比例更简单，但升高一个八度仍回到同名音。五度既有简单比例的声学基础，又能带来新的音：从 C 升五度得到 G，再从 G 升五度得到 D，因此适合作为扩展音阶的步长。

三度同样有用，后面会用它安排和弦。五度相生律只是选择以五度为主要生成关系，并不表示所有音乐都必须采用这种方法。

### 生成与排列

计算时只需要记住：升五度乘以 1.5，移低八度除以 2。继续使用 C = 240 Hz：

> C：240 Hz → G：360 Hz → 更高的 D：540 Hz → 降低八度的 D：270 Hz

把 D 除以 2，是因为 540 Hz 已经超过上方 C 的 480 Hz。降低八度后，它仍叫 D，只是音区变低了。

继续用同样的方法，可以得到 A、E、B。再从 C 向下取一个五度得到 F，并把它移到目标八度内，就得到这段五度链：

> F → C → G → D → A → E → B

归入同一个八度、按音高排序后，它们成为 C、D、E、F、G、A、B，相邻距离呈现“全—全—半—全—全—全—半”。以 C 为主音，就形成大调结构。这里的全音、半音还不是十二平均律的精确大小。

生成音的顺序可以按五度，排成音阶时则按音高。选择这段五度链、以 C 为中心，仍是音乐组织上的选择，不是物理学唯一允许的音阶。

## 纯律与和弦

**常见的五限纯律同时照顾三度与五度，使重要和弦形成简单整数比；大三和弦的典型比例是 4:5:6。**

### 大三和弦的比例

在 C—E—G 中，让 C—E 采用 5:4 的大三度，C—G 采用 3:2 的五度。以 C = 240 Hz 为例，就得到 E = 300 Hz、G = 360 Hz：

> C : E : G = 240 : 300 : 360 = 4:5:6

其中 E—G 又恰好是 6:5 的小三度。这三个音两两之间都具有简单比例，整体还对应理想谐波列的第 4、5、6 谐波，参见 [UNSW 的谐波与律制介绍](https://newt.phys.unsw.edu.au/jw/tartini-temperament.html)。

如果沿着五度链计算，同样基准下的 E 则为 303.75 Hz。纯律把它放在 300 Hz，是为了让 C—E 达到 5:4。两种安排都能形成大三和弦，但照顾的音程关系不同。

相应地，前面算出的 C—D—G 是 8:9:12，它与 C—E—G 是不同的音组合。

### 从和弦安排音阶

若让 C、F、G 上的大三和弦都采用 4:5:6，就能安排出一种常见的纯律大调音阶：C 和弦提供 C、E、G，F 和弦补入 A，G 和弦补入 B 和 D，再将各音移到同一个八度。

这时，音高的安排也考虑了它们在和弦里的关系。“纯律频率”并非一套固定的 Hz 数字，需要先确定基准音，再确定各音的比例。本文着重介绍五限纯律；纯律还有其他范围，广义上五度相生律也可归入三限纯律。

## 纯律的取舍

**照顾一些和弦，会让另一些音程偏离理想比例；一套固定音高难以兼顾所有关系。**

在刚才的纯律安排中，C、F、G 上的大三和弦都具有简单比例，但 D—A 达不到精确的 3:2。若调整 D，让它与 A 更融合，D 与其他音的关系又会改变。

歌声或能连续调整音高的乐器，可以随和声作出微调。对每个键只有一个固定音高的键盘，就难以让不同和弦、不同调里的三度与五度都同时达到理想比例。

全音也会有大小差异。看 C = 240、D = 270、E = 300 Hz：C—D 是 9:8，D—E 是 10:9，两者都叫全音，但后一个略小。相比之下，前面那组五度相生律音阶中的全音都是 9:8。差异由律制的构造方式决定，并非随意浮动。

只坚持纯五度也有局限：连续叠十二次 3:2 的五度，与升高七个八度并不完全重合。每个八度只有十二个固定音高的键盘，无法让围成一圈的十二个五度都精确等于 3:2。

这些关系之间的冲突，促使人们寻找不同的调律方案。十二平均律选择让各个调共享一致的音程结构。

## 十二平均律

**十二平均律把八度分成十二个等比例的半音，用三度、五度的少量偏差，换来固定键盘在各调中一致的音程关系。**

### 等比例的半音

每升一个半音，都乘以同一个频率倍数。十二步之后需要翻倍，因此这个倍数必须满足“连续乘十二次，结果等于 2”。

算出来，每个半音约乘以 1.05946，也就是增加约 5.95%；两个半音合成一个全音，约乘以 1.12246，也就是增加约 12.25%。

不管从哪个音出发，每个半音、每个全音的音程大小都一致。起点越高，增加的 Hz 越多，但比例不变。

### 固定键盘的取舍

五度的频率倍数变成约 1.498，接近理想的 1.5；大三度也偏离了 5:4。因此，十二平均律中的 C—E—G 仍是大三和弦，却不精确等于 4:5:6。

换来的好处是，同一套固定琴键在不同调中都能提供相同的音程关系，便于移调和转调。现代钢琴以十二平均律为基础，实际调律还会考虑琴弦非谐性，采用适当的拉伸；实测频率不一定完全等于理想模型。进一步说明可参见[音乐与音阶课程讲义](https://schwartz.scholars.harvard.edu/sites/g/files/omnuum7046/files/schwartz/files/lecture7-music.pdf)。

五度相生律着重用五度生成音高；这里的纯律安排着重照顾重要和弦；十二平均律着重让固定音高乐器在各调中保持一致的关系。它们回应的是不同的音乐需求。
